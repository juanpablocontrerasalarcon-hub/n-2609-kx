# Fabi Eurotrip

Página privada con las fotos del viaje. Proyecto independiente.

## Agregar fotos

1. Subir las imágenes a `fotos/` (lado más largo 1400 px, calidad 76).
2. Reemplazar `datos.js` por la versión actualizada.

`index.html` no se toca nunca.

## Archivos

| Archivo      | Para qué sirve                                        |
|--------------|-------------------------------------------------------|
| `index.html` | Diseño y funcionamiento. No se edita.                 |
| `datos.js`   | El contenido: qué foto va dónde y con qué texto.      |
| `mapas.js`   | Contornos de los mapas. Generado automáticamente.     |
| `fotos/`     | Las imágenes.                                         |
| `robots.txt` | Pide a los buscadores que no indexen la página.       |
